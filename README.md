Letní škola FEKT pro holky 2026
Základní koncept programu, který umožňuje měření teploty, vlhkosti v místnosti a vyhodnocení vlhkosti hlíny v květináči.
Použitý HW [LaskaKit microESP-C3 v3.2](https://www.laskakit.cz/laskakit-microesp/), [SHT40 Senzor teploty a vlhkosti vzduchu](https://www.laskakit.cz/laskakit-sht40-senzor-teploty-a-vlhkosti-vzduchu/), [LaskaKit OLED displej 128x64 0.96 I²C](https://www.laskakit.cz/laskakit-oled-displej-128x64-0-96-i2c/).
